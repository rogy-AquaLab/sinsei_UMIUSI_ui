## Camera configuration

The camera viewer reads the front (`cam1`) and down (`cam2`) camera streams from
MediaMTX through WHEP. The MediaMTX URL can be changed from the Config drawer
for the current page session. The default host is the same host serving this UI,
with port `8889`.
